  • File: what the trader's report reads now: real, demo or none. A real upload removes the demo, so someone who tried it and moved on counts as real only, and "tried the demo" is a floor. On the top card a refused file counts as a real file brought, though it gives no report to read.
  • On current code: "no" says the latest file read was not read by this deploy, which is true of every import after any deploy, even a copy change. It says not read by this deploy, not that the figures are wrong. A trader is offered a re-read only when reconstruction itself changed, so a "no" here can have no offer behind it.
  • Furthest step: the last step with a stored trace. The reveal cannot show here. Opening a chapter writes nothing, so chapter N is the furthest chapter with a fact read or an answer given. A Journal is generated by the upload, so the journal step takes one opened or written.
  • Facts read, in the report: a fact counts once its heading has been on screen for a second and then left it. A fact page closed with its heading still on screen sends nothing, so these are floors. Old dwell keys count as the fact they moved to.
  • Drawer opens: no page has a drawer now, so this can only be older events.
  • Refused, duplicates: rows are from the latest file read. Files refused counts stored refusals. A byte-identical re-upload is refused before anything is written, so those refusals are not visible here.
