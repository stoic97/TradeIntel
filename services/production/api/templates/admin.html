  • File: what the trader's report reads now: real, demo or none. A real upload removes the demo, so someone who tried it and moved on counts as real only, and "tried the demo" is a floor. On the top card a refused file counts as a real file brought, though it gives no report to read.
  • Would read differently: "yes" says today's code would build this trader's latest file read differently, the same check that offers them a re-read. A deploy that changed no reading leaves it "no".
  • Journey: each step with a stored trace. The reveal cannot show here. Opening a chapter writes nothing, so chapter N is the furthest chapter with a fact read or an answer given. A Journal is generated by the upload, so the journal step takes one opened or written.
  • Days active: India dates with any stored action. A visit that writes nothing leaves no date, so this is a floor.
  • Pay question: how close the would-pay question is: journals opened, and settled in, meaning a second file or a fortnight since the first.
